# ATS CV-Scanner

Narzędzie linii poleceń (CLI) emulujące działanie korporacyjnych systemów ATS (Applicant Tracking System) odpowiedzialnych za wstępną selekcję kandydatów. Skrypt parsuje pliki PDF za pomocą biblioteki `pypdf`, oczyszcza tekst wyrażeniami regularnymi (`re`) i wykorzystuje Pandas do analizy statystycznej częstotliwości występowania słów kluczowych, generując raport dopasowania profilu kandydata w czasie rzeczywistym.
